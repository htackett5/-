## What changed
The homepage is intentionally short. Dedicated pages: engineering projects (six case-study pages), experience, music, about, and a Metal Earth photo gallery of 18 photos. The Flak 88 model and a macro/detail view receive a feature section. The same charcoal, vivid red, and League Spartan design runs across every page.

## Publish with GitHub Desktop
1. Unzip this archive using **Extract All**.
2. In GitHub Desktop select your portfolio repository and choose **Repository → Show in Explorer**.
3. Copy *all contents* of the extracted folder into the repository folder, beside `.git`. Do not copy the enclosing folder or edit `.git`.
4. Choose **Replace** if prompted. Do not delete the old `assets` folder, because its older files are still needed.
5. Commit changes to main and **Push origin**. Let GitHub Pages deploy.
6. Your portfolio is at `https://htackett5.github.io/-/`. Open individual pages, for example `https://htackett5.github.io/-/metal-earth.html`.

## Media and attribution
The Metal Earth photos are your own. Some model titles are clear matches to official Metal Earth listings; uncertain names are explicitly marked as unconfirmed rather than asserted as official variants. The photos are snapshots of physical kits that you assembled, not CAD models you designed. Please review that distinction and verify titles before publication.
