# Helen Tackett — engineering & music portfolio (Version 3)

## Upload to GitHub Pages
Upload **the contents of this folder**, not the folder or ZIP itself, to the repository root. In GitHub, `index.html`, `style.css`, `script.js`, `resume.html`, and the `assets/` folder must be at the same level. The `assets/` folder includes all photos, videos, CAD-report figures and PDF writeups.

Use **Add file → Upload files**, drag the extracted folder contents including the assets folder, and commit to `main`. If updating existing names, accept overwrites when prompted. Check Settings → Pages and use Ctrl+Shift+R after deployment.
