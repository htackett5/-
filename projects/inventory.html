BEHIND THE BUILD.

THE DESIGN

Developed a command-line inventory management application in C with a six-option interactive menu.

IMPLEMENTATION

Used a singly linked list to store inventory records, including item IDs, prices, quantities, and categories. Implemented file saving/loading and dynamic memory cleanup.

THE RESULT & REFLECTION

Built a working inventory-management program and identified opportunities to improve duplicate-save handling, category validation, and malformed input processing.
