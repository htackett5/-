FPGA LUNAR LANDER

A modular game implemented in RTL with custom arithmetic, state and display logic.

Representative FPGA board image — the actual project is documented through its SystemVerilog source files.

DESIGN / PROCESS / RESULTS

BEHIND THE BUILD.

THE DESIGN

Developed a modular Lunar Lander game in SystemVerilog, integrating arithmetic, control, memory, timing, and display logic.

IMPLEMENTATION

Implemented custom BCD arithmetic, altitude and velocity calculations, fuel and thrust logic, landing/crash detection, synchronized inputs, and seven-segment display control.

THE RESULT

Integrated the modules into an FPGA-based game design. The source code documents the individual modules and their connections.
